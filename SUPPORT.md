## Questions and bugs

- Use GitHub Issues for reproducible bugs and feature requests.
- Include the Consilens version (`consilens-cli.sh --version`), Java version,
  source/target connector types, and a minimal configuration.
- For security reports, follow [`SECURITY.md`](SECURITY.md).

## Commercial platform

Consilens is a standalone open-source engine. The commercial platform that
integrates it provides its own support terms; this repository covers the engine,
CLI, SDK, MCP adapter and connectors.
